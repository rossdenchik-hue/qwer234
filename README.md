# ?? Трекер прочитанных книг

Консольное приложение на Python для учёта прочитанных книг. Данные сохраняются локально в JSON-файле.

## ?? Как запустить
1. Установите Python 3.8+ (если не установлен)
2. Склонируйте репозиторий: `git clone https://github.com/rossdenchik-hue/qwer234.git`
3. Перейдите в папку: `cd qwer234`
4. Запустите: `python main.py`

## ?? Меню приложения
| Команда | Описание |
|---------|----------|
| 1 | Добавить книгу (с проверкой дубликатов и валидацией оценки 1–5) |
| 2 | Показать все книги |
| 3 | Показать среднюю оценку |
| 4 | Статистика по авторам (количество книг на каждого) |
| 5 | Удалить книгу по номеру |
| 6 | Выход |
